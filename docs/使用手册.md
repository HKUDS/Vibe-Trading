## 一、快速开始（3 分钟）

```bash
# ① 安装
pip install -U vibe-trading-ai

# ② 交互式初始化（会引导填写 LLM key）
vibe-trading init

# ③ 跑第一个任务
vibe-trading run "分析汇川技术(300124.SZ)"
```

**零成本方案**（不花钱，用本地模型）：

```bash
# 先用 Ollama 拉一个模型
ollama pull qwen3.5:9b

# 配置 .env
cat >> ~/.vibe-trading/.env <<'EOF'
LANGCHAIN_PROVIDER=ollama
LANGCHAIN_MODEL_NAME=qwen3.5:9b
OLLAMA_BASE_URL=http://localhost:11434
EOF

vibe-trading run "分析汇川技术(300124.SZ)"
```

## 二、安装方式

### 方式 A：pip 安装（推荐个人使用）

```bash
pip install -U vibe-trading-ai
vibe-trading --version
```

### 方式 B：Docker（零配置）

```bash
git clone https://github.com/halo0286/Vibe-Trading.git
cd Vibe-Trading
cp agent/.env.example agent/.env     # 编辑填入 LLM key
docker compose up --build
```

访问 `http://localhost:8899`（后端 + 前端一体）。

> **Docker 中的 Ollama**：`docker-compose.yml` 已默认 `OLLAMA_BASE_URL=http://host.docker.internal:11434`，
> 并加了 `host-gateway` 映射（Linux 也适用）。

### 方式 C：源码安装（开发/定制）

```bash
git clone https://github.com/halo0286/Vibe-Trading.git
cd Vibe-Trading
pip install -e ".[dev,ashare]"

# 后端（API + Web UI）
vibe-trading serve --port 8000
# 前端开发模式（热重载）
vibe-trading serve --port 8000 --dev
```

### 方式 D：MCP 插件（接入外部 AI 客户端）

```bash
pip install -U vibe-trading-ai
```

然后在你的 AI 客户端配置（见 [§4.4](#44-mcp-server接入外部-ai-客户端)）。

## 三、初次配置

### 3.1 配置文件位置

| 优先级 | 路径 | 说明 |
|---|---|---|
| 主 | `~/.vibe-trading/.env` | **推荐**（`vibe-trading init` 生成） |
| 遗留 | `agent/.env` | 兼容旧版 |

源码依据：`src/api/helpers.py:31-32`
```python
ENV_PATH = Path.home() / ".vibe-trading" / ".env"
LEGACY_ENV_PATH = AGENT_DIR / ".env"
```

### 3.2 交互式初始化（推荐）

```bash
vibe-trading init
```
引导你选择 LLM provider 并写入 key。

### 3.3 手动配置 LLM（25 个 provider 选一）

**核心 3 个变量**：
```bash
LANGCHAIN_PROVIDER=<provider>      # provider 名
LANGCHAIN_MODEL_NAME=<model>       # 模型名
LANGCHAIN_TEMPERATURE=0.0          # 温度（金融场景建议 0）
```

**常用 provider 配置示例**：

```bash
# ① DeepSeek（国内推荐，成本低）
LANGCHAIN_PROVIDER=deepseek
LANGCHAIN_MODEL_NAME=deepseek-chat
DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_BASE_URL=https://api.deepseek.com

# ② OpenRouter（多模型中转，README 推荐）
LANGCHAIN_PROVIDER=openrouter
LANGCHAIN_MODEL_NAME=deepseek/deepseek-v4-pro
OPENROUTER_API_KEY=sk-or-xxx
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1

# ③ OpenAI
LANGCHAIN_PROVIDER=openai
LANGCHAIN_MODEL_NAME=gpt-5.5
OPENAI_API_KEY=sk-xxx

# ④ Anthropic（Claude）
LANGCHAIN_PROVIDER=anthropic
LANGCHAIN_MODEL_NAME=claude-sonnet-4-6
ANTHROPIC_API_KEY=sk-ant-xxx

# ⑤ 本地 Ollama（免费/离线）
LANGCHAIN_PROVIDER=ollama
LANGCHAIN_MODEL_NAME=qwen3.5:9b
OLLAMA_BASE_URL=http://localhost:11434

# ⑥ Kimi（月之暗面）
LANGCHAIN_PROVIDER=moonshot
LANGCHAIN_MODEL_NAME=moonshot-v1-128k
MOONSHOT_API_KEY=sk-xxx

# ⑦ Qwen（阿里 DashScope）
LANGCHAIN_PROVIDER=dashscope
LANGCHAIN_MODEL_NAME=qwen-max
DASHSCOPE_API_KEY=sk-xxx
```

**OAuth 类（无需 API key）**：
```bash
# ChatGPT OAuth（需 Codex 权限）
vibe-trading provider login openai-codex

# GitHub Copilot（需订阅）
gh auth login    # 或设置 COPILOT_GITHUB_TOKEN
```

### 3.4 配置数据源（按需，多数免费）

**A股核心**：
```bash
TUSHARE_TOKEN=xxx                  # Tushare Pro（免费注册）
MARKET_DATA_ORDER_A_SHARE=tushare,akshare,mootdx   # 数据源优先级
VIBE_TRADING_IWENCAI_KEY=xxx       # iwencai NL 研报检索（可选）
```

**可选数据源**：
```bash
FINNHUB_API_KEY=xxx        # 美股新闻/基本面
ALPHAVANTAGE_API_KEY=xxx   # 美股/宏观
TIINGO_API_KEY=xxx         # 美股
FMP_API_KEY=xxx            # 财务数据
FRED_API_KEY=xxx           # 美国宏观
GILDATA_TOKEN=xxx          # 恒生聚源 A股（商业授权）
LONGBRIDGE_APP_KEY=xxx     # 长桥证券
FUTU_HOST=127.0.0.1        # 富途 OpenD
FUTU_PORT=11111
```

> **零 token 也能用**：Tencent A股行情、mootdx（通达信）等无需任何 key。

### 3.5 验证配置

```bash
vibe-trading provider doctor       # 打印脱敏的 provider 诊断
vibe-trading data status           # 查看数据路由模式
```

## 四、五种使用方式

### 4.1 CLI（命令行）

> 以下命令与参数均来自实测 `vibe-trading --help`（非推测）。

**用法**：`vibe-trading [全局选项] <子命令> [子命令选项]`

#### 全局选项（21 个，可直接跟主命令使用）

```bash
vibe-trading -p "分析汇川技术"              # -p/--prompt 指定 prompt
vibe-trading -f prompt.txt                  # -f/--prompt-file 从文件读
vibe-trading --json                         # 机器可读 JSON 输出
vibe-trading --no-rich                      # 关闭 Rich 格式化
vibe-trading --chat                         # 交互式对话
vibe-trading --max-iter 50                  # 最大 Agent 迭代数
vibe-trading --continue <RUN_ID> "继续..."   # 继续某次运行
vibe-trading --list                         # 列出运行记录
vibe-trading --show <RUN_ID>                # 查看运行详情
vibe-trading --code <RUN_ID>                # 查看生成的代码
vibe-trading --pine <RUN_ID>                # 查看 Pine Script
vibe-trading --trace <RUN_ID>               # 重放运行 trace
vibe-trading --skills                       # 列出技能
vibe-trading --sessions                     # 列出会话
vibe-trading --session-chat <SESSION_ID>    # 继续会话对话
vibe-trading --upload <FILE_PATH>           # 上传文件
```

**Swarm 相关全局选项**：
```bash
vibe-trading --swarm-presets                # 列出所有预设
vibe-trading --swarm-inspect <PRESET>       # 检视预设（不运行）
vibe-trading --swarm-run <PRESET> [VARS]    # 运行预设
vibe-trading --swarm-list                   # 列出 swarm 运行
vibe-trading --swarm-show <RUN_ID>          # 查看 swarm 运行
vibe-trading --swarm-cancel <RUN_ID>        # 取消
vibe-trading --swarm-retry <RUN_ID>         # 重试
vibe-trading --swarm-resume                 # 重试时保留已完成任务
```

#### 子命令（19 个）

| 子命令 | 用途 | 关键子命令/选项 |
|---|---|---|
| `run` | 运行一次 prompt | `-p` `-f` `--json` `--no-rich` `--max-iter` |
| `chat` | 交互式对话 | `--chat-max-iter` |
| `serve` | 启动 API 服务器 | `--host` `--port` `--dev` |
| `init` | 交互式初始化 `.env` | — |
| `setup` | 安装/配置向导 | — |
| `dev` | 开发模式 | — |
| `update` | 更新到最新版 | — |
| `list` | 列出运行记录 | — |
| `show` | 查看运行详情 | `<RUN_ID>` |
| `provider` | LLM provider 管理 | `login <name>` · `doctor` |
| `data` | 数据路由模式 | `status` · `mode free\|paid [--budget N] [--key K]` · `usage` |
| `channels` | IM 渠道管理 | `status` · `start` · `stop` · `login` · `pairing` |
| `connector` | 券商连接器 | 见下方 |
| `portfolio` | 多券商组合（只读） | `show` |
| `alpha` | Alpha Zoo 因子 | 见下方 |
| `hypothesis` | 假设登记表 | `list` · `show` · `invalidate` |
| `playbook` | 定时研究模板 | `list` · `show` · `create` |
| `strategy-evidence` | 策略证据缓存 | `refresh` |
| `memory` | 持久记忆 | `list` · `show` · `search` · `forget` |

#### `connector` 子命令（14 个）

```bash
vibe-trading connector list                 # 列出可选连接器 profile
vibe-trading connector use <name>           # 选择默认 profile
vibe-trading connector configure <name>     # 配置本地 profile
vibe-trading connector check                # 检查就绪状态（下单前必跑）
vibe-trading connector authorize <name>     # 授权远程 MCP 连接器
vibe-trading connector account              # 账户摘要
vibe-trading connector positions            # 当前持仓
vibe-trading connector orders               # 未成交订单
vibe-trading connector quote <symbol>       # 行情
vibe-trading connector history              # 历史
```

#### `alpha` 子命令（5 个，Alpha Zoo）

```bash
vibe-trading alpha list                     # 列出已注册因子
vibe-trading alpha show <alpha_id>          # 查看因子元数据 + 源码
vibe-trading alpha bench --universe csi300 --sort ir    # 批量基准
vibe-trading alpha compare <id1> <id2> --sort ir        # 两两对比
vibe-trading alpha export-manifest          # 导出注册表 manifest (JSON)
```

#### `provider` 子命令

```bash
vibe-trading provider login openai-codex    # OAuth 登录（ChatGPT）
vibe-trading provider doctor                # 脱敏诊断（排查连线问题）
```

### 4.2 Web UI（浏览器）

```bash
# 方式 1：API server 托管前端（需先 build 前端）
cd frontend && npm install && npm run build && cd ..
vibe-trading serve --port 8000
# → http://localhost:8000

# 方式 2：开发模式（Vite 热重载）
vibe-trading serve --port 8000 --dev

# 方式 3：Docker
docker compose up --build
# → http://localhost:8899
```

**Web UI 功能**：对话式研究、回测可视化（权益曲线 vs 基准）、Alpha Zoo 浏览与对比、
Swarm 实时状态卡、Settings 管理（LLM/IM/数据源）、会话历史。

> **注意区分两个 Web 界面**：
> - **3080** = DeepSeek Harness Web GUI（AI Agent 工作台）
> - **8000 / 8899** = Vibe-Trading 自己的 Web UI

**远程访问安全规则**（源码 `#191` 修复）：
- 本机 `localhost` 访问：无需 API key
- 其他机器/LAN 访问：**必须**设置 `API_AUTH_KEY`，否则敏感端点返回 403

```bash
# 在 .env 中设置
API_AUTH_KEY=your-secret-key
# 然后在 Web UI Settings 里填入同一个 key
```

## 五、常见任务操作手册

### 5.1 研究一只股票

```bash
vibe-trading run "分析汇川技术(300124.SZ)，包括：
1. 近3个月走势与技术形态
2. 最新财报关键指标（营收/净利/ROE/毛利率）
3. 机构研报观点与目标价
4. 风险提示"
```

Agent 会自动调用 `get_market_data` · `get_financial_statements` · `get_research_reports` 等工具。

**查看结果**：
```bash
vibe-trading list                  # 列出运行记录
vibe-trading show <run_id>         # 查看详情
```

### 5.2 选股筛选

```bash
vibe-trading run "筛选 A股中同时满足以下条件的股票：
- ROE > 15%
- PE < 20
- 近3个月北向资金净流入
- 市值 > 100亿
输出前20只"
```

### 5.3 因子基准测试

```bash
# CLI 直接调用
vibe-trading alpha bench --universe csi300 --sort ir

# 或自然语言
vibe-trading run "用 gtja191 因子集在沪深300上跑基准，按 IR 排序，输出前20"
```

**因子两两对比**：
```bash
vibe-trading alpha compare alpha001 alpha042 --sort ir
```

**防过拟合严格检验**：在 prompt 中说明"做严格检验（随机对照 + OOS）"，
Agent 会调用 `run_bench_strict`。

### 5.4 回测策略

```bash
vibe-trading run "回测一个 20/60 日均线交叉策略：
- 标的：沪深300成分股
- 区间：2020-01-01 至 2025-12-31
- 初始资金：100万
- 包含手续费、印花税、滑点
- 输出：年化收益、夏普、最大回撤、胜率，以及 Brinson 归因"
```

**A股交易规则自动应用**（`china_a` 引擎）：T+1、涨跌停、印花税（万5卖出）、
过户费（万0.1）、佣金（万2.5，最低5元）。

### 5.5 启动多智能体 Swarm

```bash
vibe-trading run "启动投委会(investment_committee)，评估是否增持宁德时代(300750.SZ)"
```

**列出所有预设**：
```bash
vibe-trading run "列出所有可用的 swarm 预设"
# 或在 MCP/Web UI 中调用 list_swarm_presets
```

**30 个预设**：投委会、风控委员会、量化策略台、宏观论坛、加密研究实验室、
信用研究团队、可转债团队、地缘政治作战室等（完整列表见功能文档 §3.8）。

### 5.6 影子账户（不动真钱验证策略）

```bash
vibe-trading run "把我的20/60均线策略放进影子账户，回测最近60天，生成报告"
```

**特点**：fail-closed 门控 —— 即使产生买入信号也不会误触实盘。

### 5.7 实盘查询与下单

> 注意：`connector` 的子命令**不带券商名参数** —— 先用 `use` 选定默认 profile，再执行查询。

```bash
# ① 查看有哪些连接器 profile
vibe-trading connector list

# ② 配置某个券商（写入凭据）
vibe-trading connector configure ibkr

# ③ 选定为默认 profile
vibe-trading connector use ibkr

# ④ 下单前检查（重要！）
vibe-trading connector check

# ⑤ 查询（对默认 profile）
vibe-trading connector account                 # 账户摘要
vibe-trading connector positions               # 当前持仓
vibe-trading connector orders                  # 未成交订单
vibe-trading connector quote AAPL              # 行情
vibe-trading connector history                 # 历史

# ⑥ 远程 MCP 连接器需先授权
vibe-trading connector authorize <name>

# ⑦ 多券商组合总览（只读）
vibe-trading portfolio show
```

**18 个连接器**：IBKR、Alpaca、Binance、OKX、Futu、Longbridge、Robinhood、Tiger、
MT5、Zerodha、Dhan、Shoonya、Upbit、eToro、Scalable、Trading212、KIS、Toss

> ⚠️ **多数连接器为 paper/read-only**。没有 paper/live 结构区分的券商会**硬拒绝**非 paper 配置。
> 实盘前务必跑 `trading_check`。

### 5.8 切换数据路由模式

```bash
# 查看当前模式
vibe-trading data status

# 切换到免费公共数据（默认）
vibe-trading data mode free

# 切换到付费数据（QVeris 高级数据）
vibe-trading data mode paid --budget 10.0 --key <premium-key>

# 查看用量
vibe-trading data usage
```

### 5.9 开启数据缓存（加速重复回测）

```bash
# 在 .env 中
VIBE_TRADING_DATA_CACHE=1
```
缓存位置：`~/.vibe-trading/cache`（7 个数据源：tushare/okx/ccxt/akshare/mootdx/yfinance/futu）。

### 5.10 记忆管理

```bash
vibe-trading memory list              # 列出记忆条目
vibe-trading memory show <id>         # 查看详情
vibe-trading memory search "宁德时代"  # 搜索
vibe-trading memory forget <id>       # 遗忘
```

### 5.11 读取 PDF 研报

```bash
vibe-trading run "读取 /path/to/report.pdf，提取核心观点和评级"
```
`read_document` 工具支持文本 PDF + 扫描件 OCR 回退。

### 5.12 导出策略

```bash
vibe-trading run "把刚才的策略导出成 vnpy 格式"
vibe-trading run "为这个策略生成 Pine Script 代码"
```

## 七、故障排查

### 7.1 `dsh: command not found`

**已修复**。本机已创建持久启动器 `~/.local/bin/dsh` 并写入 `~/.bashrc` 的 PATH。

若仍遇到：
```bash
source ~/.bashrc          # 当前终端立即生效
# 或直接新开终端
```

根本原因：dsh 只存在于 npx 临时缓存，PATH 中无稳定入口。

### 7.2 LLM 连不上

```bash
vibe-trading provider doctor       # 一键诊断（脱敏输出）
```

**常见原因**：
- key 未填或填错
- base_url 不匹配（国内 provider 常用自定义 endpoint）
- 网络/代理问题（可用 `VIBE_TRADING_DISABLE_HTTP_PROXY=1` 排查）
- Docker 中访问宿主机 Ollama 需用 `host.docker.internal`

### 7.3 数据拉不到

```bash
vibe-trading data status           # 确认路由模式
```

**排查顺序**：
1. 检查 `TUSHARE_TOKEN` 是否有效（`ts.pro_api(token=...)` 直连测试）
2. 确认 ticker 格式（A股用 `300124.SZ` 或 `600519.SH`）
3. 检查是否为**北交所老号段**（`43x/83x/87x` 已迁移至 `920xxx`，会静默返回空）
4. 部分免费源有反爬限流，可切换数据源或等待

### 7.4 远程访问 403

```
Remote API access requires an API key.
```
**修复**：设置 `API_AUTH_KEY`，并在 Web UI Settings 中填入同一 key。

### 7.5 端口被占用

```bash
# 查看
ss -tlnp | grep -E "8000|8899|3080"

# 换端口
vibe-trading serve --port 8080
```

### 7.6 Web UI 打不开

```bash
# 前端未 build 时 serve 无静态资源
cd frontend && npm install && npm run build && cd ..
vibe-trading serve --port 8000

# 或用开发模式
vibe-trading serve --port 8000 --dev
```

### 7.7 扫描件 PDF 读不出

```bash
# 需要 OCR 引擎
VIBE_TRADING_OCR_ENGINE=<engine>
VIBE_TRADING_OCR_LLM_MODEL=<model>
```

### 7.8 依赖缺失

项目采用**可选依赖组**，缺什么装什么：
```bash
pip install -e ".[openbb,stats,anthropic,ashare,krx,discord,copilot]"
```
缺依赖时对应测试/功能会 `importorskip` 静默跳过。

### 7.9 中文路径/编码问题

```bash
LANG=C.UTF-8
export PYTHONIOENCODING=utf-8
```

## 八、安全须知

### 8.1 默认安全设计（已内置）

| 机制 | 说明 |
|---|---|
| **shell 工具默认关闭** | `bash`/`background_run` 等需显式 `VIBE_TRADING_ENABLE_SHELL_TOOLS=1` |
| **fail-closed 交易门控** | 无 paper/live 区分的券商仅允许 paper + read-only |
| **路径白名单** | `VIBE_TRADING_ALLOWED_FILE_ROOTS` / `_RUN_ROOTS` |
| **API 认证** | 非 loopback 访问强制 `API_AUTH_KEY` |
| **密钥脱敏** | 日志/Settings 掩码显示；access log 脱敏 `api_key=`/`ticket=` |
| **日志脱敏** | logsystem 自动脱敏 password/token/secret/id_card/bank_card 等 15 类 |
| **Shadow Account** | 新策略先在影子账户验证，不触实盘 |

### 8.2 使用建议

1. **不要在对话里明文粘贴 API key / token**（会留在会话历史）
2. **实盘前必须**跑 `connector check`，并先用影子账户验证
3. **开启 shell 工具需谨慎**（RCE 风险面），仅在受控环境启用
4. **远程部署必须设 `API_AUTH_KEY`**，不要用 `--host 0.0.0.0` 裸奔
5. **定期审查** `~/.vibe-trading/.env` 的凭据
6. **Docker 部署**已默认只发布到 `127.0.0.1:8899`

### 8.3 数据合规

- 免费公开数据源（Tencent/mootdx 等）**无需授权**，可直接使用
- Tushare/AlphaVantage 等需遵守各自服务条款与频率限制
- GILDATA（恒生聚源）为**商业授权**数据，需自行确认许可
- **输出仅为研究参考，不构成投资建议**
