## 一、项目定位

**Vibe-Trading** 是一个**自然语言驱动的金融研究与量化交易 AI Agent 工作台**。它以 ReAct 智能体为中枢，串联：
**多市场数据接入 → 因子研究 → 策略回测 → 风险管理 → 模拟/实盘交易 → IM 推送 → 多智能体协作**，
并提供 CLI / Web UI / REST API / MCP Server 四种交互方式。

## 四、使用场景（详细）

### 场景 1：自然语言投研（最常用）

**目标用户**：个人投资者、研究员、分析师

**典型任务**：
- "分析一下汇川技术最近的走势和基本面"
- "帮我找 A股里 ROE > 15% 且 PE < 20 的股票"
- "贵州茅台最近三个月的机构研报怎么看？"
- "对比宁德时代和比亚迪的财务质量"

**工作流**：
```
vibe-trading run "分析汇川技术(300124.SZ)"
  → Agent 理解意图
  → 调用 get_market_data / get_financial_statements / get_research_reports
  → 加载相关 Skill（如 fundamental-filter）
  → LLM 综合分析
  → 输出结构化报告
```

**涉及功能**：`get_market_data` · `get_financial_statements` · `get_research_reports` ·
`get_stock_news` · `screen_market` · `web_search` · 95 个 Skill

---

### 场景 2：因子研究与 Alpha 挖掘

**目标用户**：量化研究员、因子开发者

**典型任务**：
- "用 gtja191 的因子在沪深300上跑一遍基准，按 IR 排序"
- "对比 alpha001 和 alpha042 的 IC 表现"
- "这个因子是不是只在跟踪市场 beta？帮我做严格检验"

**工作流**：
```bash
# CLI
vibe-trading alpha bench --universe csi300 --sort ir
vibe-trading alpha compare alpha001 alpha042 --sort ir
```
```
# 或自然语言
vibe-trading run "bench gtja191 factors on csi300 and rank by IC mean"
```

**涉及功能**：`alpha_zoo` · `alpha_bench` · `factor_analysis` · `factor_research_committee`(Swarm) ·
`factor-research`(Skill) · 462 个因子 · `run_bench_strict`（防过拟合）

---

### 场景 3：策略回测与归因

**目标用户**：策略开发者、量化交易者

**典型任务**：
- "用双均线策略回测沪深300成分股，2020年至今"
- "这个策略的回撤为什么这么大？帮我做归因分析"
- "加上手续费和滑点后收益还剩多少？"

**工作流**：
```
vibe-trading run "backtest a 20/60 MA crossover on csi300 from 2020-01-01, include costs"
  → backtest 工具
  → china_a 引擎（含 A股交易规则：T+1、涨跌停、印花税、过户费）
  → 输出绩效指标 + 归因 + 风险 X-Ray
```

**涉及功能**：`backtest` · 14 个市场引擎 · `attribution`（Brinson）· `risk_xray` ·
`factor_costs`（成本建模）· `partial_fill`（部分成交）· `execution_algos`（TWAP/VWAP/IS）·
`backtest-diagnose`(Skill)

---

### 场景 4：多智能体协作研究（Swarm）

**目标用户**：需要多视角论证的复杂决策

**典型任务**：
- "启动投委会，评估是否增持宁德时代"
- "组织宏观策略论坛，讨论美联储降息对 A股的影响"
- "让风控委员会审查我这个组合的风险"

**工作流**：
```
vibe-trading run "run the investment committee on 300750.SZ"
  → 加载 investment_committee 预设
  → 启动多 Agent（多方/空方/风控/经理）
  → DAG 编排（upstream 失败阻断 downstream）
  → 汇总决策
```

**涉及功能**：30 个 Swarm 预设 · `get_swarm_status` · `list_swarm_presets` · Research Goal 系列

---

### 场景 5：影子账户（策略验证，不动真钱）

`render_shadow_report` · `shadow-account`(Skill)

```bash
# 1. 安装（已修复 dsh 命令，可直接使用）
pip install -U vibe-trading-ai
# 或
npx @deepseek-ai/dsh web

# 2. 初始化（配置 LLM key）
vibe-trading init

# 3. 运行
vibe-trading run "分析汇川技术(300124.SZ)"      # CLI
dsh web                                          # Web UI → http://127.0.0.1:3080

# 4. 常用操作
vibe-trading list                                # 查看历史运行
vibe-trading provider doctor                     # 诊断 LLM 连通性
vibe-trading channels status                     # IM 渠道状态
```

**推荐 LLM**：本地 `ollama`（免费/离线）或 `deepseek`（国内可用、成本低）。
