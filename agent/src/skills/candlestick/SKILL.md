# 股票K线形态识别助手

## 功能说明

本技能是一款专业的K线形态智能识别工具，基于经典技术分析理论，能够自动识别20余种常见K线形态和组合形态，为投资者提供客观的技术面分析参考。无论是入门投资者还是资深交易者，都可以借助本工具快速判断当前K线形态所蕴含的市场信号。

**核心价值：**
- 快速识别多空力量转换信号
- 辅助判断趋势反转和持续形态
- 提供形态的历史胜率参考
- 给出明确的操作建议和风险提示

## 适用场景

1. **日内交易决策**：识别短期K线形态，辅助日内买卖点判断
2. **波段操作参考**：通过日K/周K形态判断中期趋势变化
3. **复盘学习**：对历史K线进行形态标注，加深技术分析理解
4. **持仓监控**：跟踪持仓股票的K线形态变化，及时发现预警信号
5. **新手入门**：帮助初学者快速认识各类K线形态及其含义

## 使用方法

### 第一步：提供K线数据

请提供待分析的K线数据，支持以下格式：

**格式一：OHLC数据列表（推荐）**
```
日期,开盘价,最高价,最低价,收盘价
2026-07-01,15.20,15.80,15.00,15.60
2026-07-02,15.60,16.00,15.40,15.80
...
```

**格式二：简单描述**
```
最近5天K线：
第1天：开15.2 高15.8 低15.0 收15.6 阳线
第2天：开15.6 高16.0 低15.4 收15.8 阳线
...
```

**格式三：形态描述**
直接描述你看到的形态，如"连续三根大阳线后出现十字星"

### 第二步：选择分析维度

系统将自动识别并询问你关注的重点：
- 反转形态（顶/底部信号）
- 持续形态（趋势延续信号）
- 全部形态综合分析

### 第三步：获取分析报告

自动生成结构化分析报告，包含：
- 识别出的所有形态列表
- 每个形态的含义解读
- 形态强度评级（强/中/弱）
- 历史胜率统计参考
- 操作建议和止损位建议
- 风险提示
