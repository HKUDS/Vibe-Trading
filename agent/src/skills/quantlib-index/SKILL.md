# quantlib_call function index

Use `quantlib_call(action="call", module="...", function="...", kwargs={...})` with a short module name below. The tool is pure computation and does not fetch network data or write files. Use `action="describe"` only when the function signature or docstring is missing from this index. `action="list"` is a fallback for a module added after this skill was published.

- `MissingInputError(missing: 'Iterable[str]', model: 'str') -> 'None'` — Raised when a model cannot run because inputs are absent.
- `ValuationError(signature unavailable)` — Base class for every refusal a valuation model makes.
- `normalize_currency(value: 'str', *, field_name: 'str' = 'currency') -> 'str'` — Normalize a currency code to its canonical uppercase form.
- `require_inputs(supplied: 'Mapping[str, Any]', required: 'Iterable[str]', model: 'str') -> 'None'` — Refuse to run unless every required input is present and usable.
- `require_positive(value: 'float', name: 'str', model: 'str') -> 'float'` — Check a value that is meaningless at or below zero.

## `valuation.dcf`
- `DCFResult(wacc_build: 'WACCResult', fcff_bridge: 'tuple[FCFFYear, ...]', discounted_fcff: 'tuple[DiscountedCashFlow, ...]', pv_of_explicit_fcff: 'float', terminal_value: 'TerminalValueResult', terminal_value_method: 'str', discounting_convention: 'str', terminal_discount_factor: 'float', pv_of_terminal_value: 'float', enterprise_value: 'float', net_debt_bridge: 'NetDebtBridgeResult', equity_value: 'float', value_per_share: 'float') -> None` — The full DCF: every bridge, both terminal values, and the final price.
- `DiscountedCashFlow(year: 'int', fcff: 'float', wacc_rate: 'float', time_period: 'float', discount_factor: 'float', present_value: 'float') -> None` — One projection year's FCFF, discounted to present value.
- `FCFFYear(year: 'int', ebit: 'float', tax_rate: 'float', nopat: 'float', depreciation_amortization: 'float', capex: 'float', delta_nwc: 'float', fcff: 'float') -> None` — One projection year's bridge from EBIT to free cash flow to the firm.
- `NetDebtBridgeResult(enterprise_value: 'float', total_debt: 'float', cash_and_equivalents: 'float', minority_interest: 'float', preferred_equity: 'float', associate_investments: 'float', equity_value: 'float', diluted_shares: 'float', value_per_share: 'float') -> None` — The bridge from enterprise value to value per share.
- `TerminalValueResult(wacc_rate: 'float', terminal_growth: 'Assumption', perpetuity_terminal_value: 'float', terminal_year_ebitda: 'float', exit_multiple: 'Assumption', exit_terminal_value: 'float', implied_ev_ebitda_multiple: 'float', implied_perpetuity_growth: 'float', gdp_growth_ceiling: 'float', growth_exceeds_gdp_ceiling: 'bool') -> None` — Both terminal-value estimates, each cross-checked against the other.
- `WACCResult(risk_free_rate: 'float', beta: 'float', equity_risk_premium: 'float', size_premium: 'float', country_risk_premium: 'float', cost_of_equity: 'float', pretax_cost_of_debt: 'float', tax_rate: 'float', cost_of_debt_after_tax: 'float', capital_structure_basis: 'str', equity_weight: 'float', debt_weight: 'float', wacc: 'float') -> None` — The WACC build, with every component that fed it kept visible.
- `discount_fcff(fcff_years: 'Sequence[FCFFYear]', *, wacc_rate: 'float', discounting_convention: 'str') -> 'tuple[DiscountedCashFlow, ...]'` — Discount every projection year's FCFF to present value.
- `equity_bridge(*, enterprise_value: 'float', total_debt: 'float', cash_and_equivalents: 'float', minority_interest: 'float', preferred_equity: 'float', associate_investments: 'float', diluted_shares: 'float') -> 'NetDebtBridgeResult'` — Bridge enterprise value to equity value and value per share.
- `fcff_bridge(*, ebit: 'Sequence[float]', tax_rate: 'float', depreciation_amortization: 'Sequence[float]', capex: 'Sequence[float]', delta_nwc: 'Sequence[float]') -> 'tuple[FCFFYear, ...]'` — Build the EBIT -> FCFF bridge for every projection year.
- `run_dcf(inputs: 'Mapping[str, Any]', *, capital_structure_basis: 'str', discounting_convention: 'str', terminal_value_method: 'str', gdp_growth_ceiling: 'float' = 0.04) -> 'DCFResult'` — Run a complete DCF from a flat mapping of named inputs.
- `sensitivity_grid(fcff_years: 'Sequence[FCFFYear]', *, wacc_values: 'Sequence[float]', growth_values: 'Sequence[float]', discounting_convention: 'str', total_debt: 'float', cash_and_equivalents: 'float', minority_interest: 'float', preferred_equity: 'float', associate_investments: 'float', diluted_shares: 'float') -> 'pd.DataFrame'` — Value-per-share sensitivity to WACC and perpetuity terminal growth.
- `terminal_value(*, final_year_fcff: 'float', terminal_year_ebitda: 'float', wacc_rate: 'float', terminal_growth: 'Assumption', exit_multiple: 'Assumption', gdp_growth_ceiling: 'float' = 0.04) -> 'TerminalValueResult'` — Compute both terminal-value estimates and cross-validate them.
- `wacc(*, risk_free_rate: 'float', beta: 'float', equity_risk_premium: 'float', pretax_cost_of_debt: 'float', tax_rate: 'float', capital_structure_basis: 'str', market_value_of_equity: 'float | None' = None, market_value_of_debt: 'float | None' = None, target_equity_weight: 'float | None' = None, target_debt_weight: 'float | None' = None, size_premium: 'float' = 0.0, country_risk_premium: 'float' = 0.0) -> 'WACCResult'` — Build the weighted average cost of capital.

## `valuation.threestatement`
- `BalanceSheet(period: 'int', cash: 'float', net_working_capital: 'float', ppe: 'float', revolver_balance: 'float', paid_in_capital: 'float', retained_earnings: 'float') -> None` — One period's balance sheet. Every field is a rollforward, never an input.
- `BalanceSheetError(period: 'int', assets: 'float', liabilities: 'float', equity: 'float', tolerance: 'float') -> 'None'` — Raised when a balance sheet fails ``assets == liabilities + equity``.
- `CashFlowStatement(period: 'int', net_income: 'float', depreciation_amortization: 'float', change_in_net_working_capital: 'float', capex: 'float', dividends_paid: 'float', revolver_draw: 'float', revolver_repayment: 'float', financing_activities: 'float', net_change_in_cash: 'float') -> None` — One period's cash flow statement, bridging net income to the cash change.
- `ConvergenceError(period: 'int', iterations: 'int', last_delta: 'float', tolerance: 'float') -> 'None'` — Raised when the interest/revolver circularity fails to converge.
- `IncomeStatement(period: 'int', revenue: 'float', gross_profit: 'float', opex: 'float', ebitda: 'float', depreciation_amortization: 'float', ebit: 'float', interest_expense: 'float', pretax_income: 'float', tax_expense: 'float', net_income: 'float') -> None` — One period's income statement, linked end to end.
- `PeriodResult(period: 'int', income_statement: 'IncomeStatement', cash_flow_statement: 'CashFlowStatement', balance_sheet: 'BalanceSheet', converged: 'bool', iterations: 'int') -> None` — One projected period's linked statements plus circularity diagnostics.
- `ThreeStatementProjection(opening_balance_sheet: 'BalanceSheet', periods: 'tuple[PeriodResult, ...]') -> None` — A full multi-period projection: the opening balance sheet plus every period.
- `check_balance_sheet(balance_sheet: 'BalanceSheet', tolerance: 'float' = 1e-09) -> 'None'` — Assert that a balance sheet balances, or raise naming the residual.
- `project_three_statement(opening: 'Mapping[str, float]', drivers: 'Mapping[str, Sequence[float]]', circularity_tolerance: 'float' = 1e-10, max_circularity_iterations: 'int' = 100, balance_tolerance: 'float' = 1e-09) -> 'ThreeStatementProjection'` — Project linked income, cash flow and balance-sheet statements forward.

## `var_backtest`
- `ConditionalCoverageResult(statistic: 'float', p_value: 'float', rejected: 'bool', significance: 'float', kupiec: 'KupiecResult', independence: 'IndependenceResult') -> None` — Outcome of the joint Christoffersen conditional-coverage test.
- `IndependenceResult(transitions: 'tuple[int, int, int, int]', prob_breach_after_calm: 'float', prob_breach_after_breach: 'float', statistic: 'float', p_value: 'float', rejected: 'bool', significance: 'float', identified: 'bool') -> None` — Outcome of the Christoffersen independence test.
- `KupiecResult(observations: 'int', violations: 'int', expected_violations: 'float', violation_rate: 'float', expected_rate: 'float', statistic: 'float', p_value: 'float', rejected: 'bool', significance: 'float') -> None` — Outcome of the Kupiec proportion-of-failures test.
- `TrafficLightResult(zone: 'str', violations: 'int', observations: 'int', cumulative_probability: 'float', scaling_factor: 'float | None', scaling_factor_basis: 'str') -> None` — Basel supervisory zone for an observed exception count.
- `VarBacktestReport(confidence: 'float', observations: 'int', violations: 'int', dropped_observations: 'int', kupiec: 'KupiecResult', independence: 'IndependenceResult', conditional_coverage: 'ConditionalCoverageResult', traffic_light: 'TrafficLightResult', breach_dates: 'tuple[object, ...] | None') -> None` — Every test in this module, run over one aligned return/VaR pair.
- `basel_traffic_light(violations: 'int', observations: 'int', confidence: 'float' = 0.99) -> 'TrafficLightResult'` — Place an exception count in the Basel supervisory zone.
- `christoffersen_conditional_coverage(breaches: 'Sequence[bool] | np.ndarray', confidence: 'float' = 0.99, significance: 'float' = 0.05) -> 'ConditionalCoverageResult'` — Test coverage and independence jointly.
- `christoffersen_independence(breaches: 'Sequence[bool] | np.ndarray', significance: 'float' = 0.05) -> 'IndependenceResult'` — Test whether breaches cluster in time.
- `kupiec_pof(violations: 'int', observations: 'int', confidence: 'float' = 0.99, significance: 'float' = 0.05) -> 'KupiecResult'` — Test whether the breach *count* matches the model's claimed level.
- `var_backtest(returns: 'pd.Series | np.ndarray | Sequence[float]', var: 'pd.Series | np.ndarray | Sequence[float] | float', confidence: 'float' = 0.99, significance: 'float' = 0.05) -> 'VarBacktestReport'` — Run every test in this module over one return/VaR pair.
- `violation_indicator(returns: 'pd.Series | np.ndarray | Sequence[float]', var: 'pd.Series | np.ndarray | Sequence[float] | float') -> 'np.ndarray'` — Flag the days on which the realised loss exceeded the VaR forecast.

## `volatility`
- `diagnose_iv_surface(observations: 'Sequence[Mapping[str, Real]]', *, spot: 'Real', risk_free_rate: 'Real' = 0.0, dividend_yield: 'Real' = 0.0) -> 'dict[str, object]'` — Check observed IV slices against European call-price inequalities.
- `heston_characteristic_function(u: 'complex | float', S0: 'float', T: 'float', r: 'float', q: 'float', v0: 'float', kappa: 'float', theta: 'float', sigma_v: 'float', rho: 'float') -> 'complex'` — Evaluate the Heston characteristic function phi(u) for log(S_T).
- `heston_feller_condition(kappa: 'float', theta: 'float', sigma_v: 'float') -> 'dict[str, float | bool]'` — Check Feller condition (2 * kappa * theta > sigma_v**2).
- `heston_price(S0: 'float', K: 'float', T: 'float', r: 'float', v0: 'float', kappa: 'float', theta: 'float', sigma_v: 'float', rho: 'float', option_type: 'str' = 'call', q: 'float' = 0.0, integration_limit: 'float | None' = None) -> 'float'` — Price a European option under the Heston stochastic volatility model.
- `implied_volatility_surface(observations: 'Sequence[Mapping[str, Real]]', *, spot: 'Real', strikes: 'Sequence[Real] | None' = None, expiries: 'Sequence[Real] | None' = None) -> 'dict[str, object]'` — Build a bounded strike-by-expiry grid from observed implied volatilities.
