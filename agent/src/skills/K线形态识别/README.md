# 股票K线形态识别助手 - Skill包说明

## 文件结构
```
股票K线形态识别助手/
├── SKILL.md                      # 技能描述文件（必须）
├── scripts/
│   └── kline_pattern_analyzer.py # K线形态计算与识别脚本
└── README.md                     # 本文件
```

## 安装方法

### 方法一：通过WorkBuddy导入（推荐）
1. 打开WorkBuddy桌面版
2. 左侧菜单 → 技能 → 本地技能 → 导入技能
3. 选择本文件夹中的 SKILL.md
4. 导入成功后即可使用

### 方法二：打包上传到SkillHub
1. 将整个文件夹压缩为 ZIP 格式
2. 访问 https://skillhub.cn
3. 登录 → 开发者中心 → 发布Skill
4. 上传ZIP包，填写信息，提交审核

## 测试用例

### 测试用例1：早晨之星形态识别
**输入：**
```
日期,开盘,最高,最低,收盘,成交量
2026-07-01,20.50,20.80,19.80,19.90,100000
2026-07-02,19.90,20.10,19.20,19.30,120000
2026-07-03,19.30,19.50,18.80,18.90,150000
2026-07-04,18.90,19.00,18.50,18.80,130000
2026-07-07,18.80,19.20,18.60,19.10,110000
2026-07-08,19.10,19.30,18.70,19.00,95000
2026-07-09,19.00,19.50,18.20,18.30,180000
2026-07-10,18.30,18.50,18.20,18.40,80000
2026-07-11,18.40,19.80,18.30,19.60,220000
```
**预期输出：** 识别出早晨之星形态、看涨吞没形态、大阳线等

### 测试用例2：双顶形态识别
**输入：**
```
请分析该股是否构成双顶形态：
股价从10元涨到15元（第一顶），回调到12元，
再次涨到14.8元（第二顶），然后跌破12元颈线位，现价11.5元
```
**预期输出：** 识别双顶形态，给出目标位测算和操作建议

### 测试用例3：单根K线形态判断
**输入：**
```
今天K线：开盘15.5，最高16.2，最低15.3，收盘16.1
这是什么形态？
```
**预期输出：** 识别为大阳线，给出多头信号解读

### 测试用例4：多形态综合分析
**输入：**
```
连续下跌5天后，出现一根长下影线的小阳线，
第二天跳空高开收大阳线，完全包裹前一天的实体
```
**预期输出：** 识别锤头线+看涨吞没，判断为底部反转信号
